### 1.2 命令行编译（已验证：`BUILD_EXIT=0`，产出 908,800 字节 exe）

```bat
@echo off
cd /d "%~dp0"
call "C:\Program Files (x86)\Intel\Composer XE 2013 SP1\bin\compilervars.bat" intel64 vs2013
ifort /Qopenmp /O2 /I. ^
  time_elapsed.f90 time_print.f90 rn_grid.f90 dambreaking_sph.f kernel.f wavemaker.f ^
  s_grid.f interforce.for interforce1.for singlestep.for singlestep1.for ^
  sp.for sp1.for timeintegration.for /exe:gutishuntaili.exe
```

要点：

1. **必须**先 `call compilervars.bat intel64 vs2013`（`vs2010` / `vs2012` 会报 `Visual Studio ... is not found`，因为本机注册表登记的是 VS2013）。
2. **模块顺序有要求**：`rn_grid.f90` 定义 `module rn_grid`，`sp.for`、`sp1.for`、`s_grid.f` 都 `use rn_grid`；`rn_grid.f90` 必须排在它们之前（本次顺序已满足）。
3. `time_elapsed.f90` 里 `use dfport`，Intel 编译器自带该模块，无需额外处理。
4. 若需要逐步调试，把 `/O2` 换成 `/Od /Zi /Qopenmp` 并加 `/debug:full`。

## 2. 程序现状：具备的能力

**总体**：二维、弱可压缩、拉格朗日粒子法（SPH），水-冰两相耦合，双时间步显式积分，OpenMP 并行。源码与张宁波博士论文（哈工程，2020）同源（`dambreaking_sph.f:3` 注释 "Improved by Zheng Xing in HEU 2013"）。

### 2.1 物理与力学模型

| 能力 | 实现位置 | 说明 |
|---|---|---|
| 弱可压缩水相（Tait 状态方程，γ=7） | `menu.inc`：`omiga=7`、`rho01=1000`、`c0` 由 `dt`/`s_rad` 定 | 声速取 10 倍最大流速量级 |
| 冰相弹塑性 + Drucker-Prager 屈服 | `interforce.for:296-302`（`ys=qfqd*sgm`、`arf`）、`:305`（`tpff` 塑性修正） | 平面应力/平面应变假设下的 2D 冰本构 |
| 内聚力软化破坏 | `interforce.for:433-437`（`qfqd=q0-rx*ljsxyb`，`rx=1.2E/10`） | 等效塑性应变累积到阈值后强度退化，标记 `sh=1/2` |
| 应变率、Jaumann 应力率 | `interforce.for`（`sr/tr` → Jaumann 旋转） | 大变形下的客观应力率 |
| 人工应力抑制拉伸不稳定 | `interforce.for:931`（`rg`，`(w/wij)^4`，指数 `yt=4.0`） | Monaghan 型人工应力 |
| 人工粘性 | `menu.inc`：冰 `alpha_phai=1.0/belda_phai=1.0`，水 `alpha_phai1=0.2/belda_phai1=0.0` | 标准 Monaghan 形式 |
| SPH_SFDI 核函数一阶梯度修正 | `interforce.for:116-128`（`NL1/NL2`，L=Σr⊗∇w 求逆）、`interforce1.for:782-823` | 改善边界与不规则分布处梯度精度，直接提高应变率求解质量 |
| 冰-水耦合：冰粒子作为水的边界虚粒子 + 密度比修正 | `interforce.for:984`（`eb=0.005`）、`:1116`（`eb=epsino`）；`interforce1.for:1182`（`(p(nj)+p(i))*cor*massj/(rho_j*rho01)`） | 解决冰-水密度比（900/1000）导致的相互作用力不对等 |
| 冰-水相互作用力对等（双时间步同步） | 冰侧 `dt`、水侧 `dt1=45dt`（`bs=45`），`dyl/dyva` 反力累积（`interforce1.for:1521-1548`） | 冰粒子与水的耦合按同一物理时刻更新 |
| 碎裂面粒子对屏蔽 | `interforce.for:174-227`（`(dis-dis1)/dis1 ≥ r0/r01` 时 `sx=3/4`、`w=0`、`cor=0`） | 断裂后两侧粒子不再相互"拉拽"，避免非物理粘连 |
| 水相自由面与壁面边界 | `singlestep1.for:92`（底部镜像）、`:107`（侧壁）、`:137`（活塞）、`:156`（右端），`sx=3` 层虚粒子；Adami 压力外推 `interforce1.for:696-697` | 镜像 + 压力外推组合 |
| 数值造波（解析活塞） | 主程序/`wavemaker.f`：`wh=0.025 m`、`period=1.2 s`，`wmv=wa*wp/2*cos(wp*t)`、`wmx=wa/2*sin(wp*t)+0.1` | `wavemaker.f` 的 Goring 形式在 `singlestep1.for:60` 被注释，实际用解析运动 |
| 消波区 | `timeintegration.for:163`：`v(i)=1*(exp(((x-lf+ld)/ld)^np)-1)/(e-1)`，`lf=16`、`ld=3`、`np=6` | 右端指数型速度衰减 |
| 双时间步预测-校正 | `timeintegration.for`：冰 `dt`、水 `dt1=45dt`（`dt1=2.25e-4`）；`singlestep.for:222/493`、`singlestep1.for:227/393` | 兼顾冰相稳定与计算成本 |

## 3. 缺口：与本课题（液舱晃荡）的距离

| # | 缺口 | 现状证据 | 影响 |
|---|---|---|---|
| 1 | 无液舱几何 | 主程序只初始化水槽 + 冰板，无舱底/舱壁/舱顶几何 | 无法算晃荡 |
| 2 | 无舱壁/舱顶虚粒子与压力外推 | 现有虚粒子只覆盖水槽底部、侧壁、活塞 | 舱壁冲击压力无从计算 |
| 3 | 无刚体运动自由度 | 活塞是给定解析运动，无 6-DOF 或浮体运动方程；`cdyl`（冰反力）在 `interforce1.for:1526-1529` 有累积但**无消费点** | 无法实现"浮冰—船体—液舱"双向耦合 |
| 4 | 无晃荡专用输出 | 无舱壁压力时程/峰值分布、晃荡力矩、自由面探针、能量分配 | 结果无法直接支撑规律分析 |
| 5 | δ-SPH 密度耗散未启用 | `interforce.for:963`、`interforce1.for:1179/1236` 均为**注释状态**；`menu.inc` 的 `deltf=0.1` 未被使用 | 强冲击下压力振荡难抑制（开题报告已承诺该改进项，需注明"待标定启用"） |
| 6 | 无粒子移位/自由面处理 | 仅 `timeintegration.for:475-478` 有系数 5e-5 的经验位置扰动；无 SPT、无自由面负压截断、无密度重初始化 | 长时间计算易出现粒子聚集与压力噪声 |
| 7 | 邻域搜索写死区域 | `sp.for:34/76` 把冰区限定在 `x∈[5,11]`、`y≥0.3` | 加液舱后冰/水位置变化会漏搜索 |
| 8 | 参数全硬编码 | `menu.inc` + 主程序常量 | 多工况参数化扫描需反复改码重编译 |
| 9 | 仅二维、无 MPI | `dim=2`；并行只有 OpenMP（31 线程写死） | 三维受限；加液舱后粒子数翻倍，单机 GPU/MPI 缺位 |
| 10 | 缺液舱晃荡验证算例 | 现有验证只有溃坝/波浪-浮冰 | 无法自证晃荡计算正确性（可对标 Delorme 2009、Souto-Iglesias 2006） |
| 11 | 无冰-舱壁接触模型 | 冰只与水、与自身交互 | 冰撞舱壁这一激励路径缺失 |

## 4. 改进路线（按开题报告进度，5 个阶段）

### 阶段 0：可配置化与工程化（约 1–2 周）
- `menu.inc` 与主程序常量改为 `namelist` 输入（`case.nml`），支持不改码切工况；
- 解除 `sp.for` 的写死区域，改为按粒子实际分布建搜索范围；
- 单份工作副本 + Git（已完成：仓库 `D:\SPH-program`，`main` 分支，`v0-baseline` 标签）；
- 新增 `build.bat` / `run.bat`（编译与运行一条命令），输出目录切到 `output\`。

**验收**：改 `case.nml` 能跑两种工况，`git diff` 干净。

### 阶段 1：液舱模块（约 3–4 周）
- 舱底/舱壁/舱顶多层虚粒子（沿用 `sx=3` 镜像 + Adami 外推），支持任意矩形舱与充液率 30%/50%/70%；
- 舱壁压力时程与峰值分布、晃荡力矩、自由面高度探针（x=舱中心/舱壁附近）、液相/冰相/系统能量输出；
- 验证：静水静压、一阶模态固有频率、强迫横摇冲击压力（对标 Delorme 2009 试验）。

**验收**：一阶固有频率误差 <5%，冲击压力峰值趋势与试验一致。

### 阶段 2：刚体运动与冰-舱壁接触（约 3–4 周）
- 2D 三自由度（横荡/垂荡/横摇）刚体运动方程，舱壁虚粒子速度/加速度由刚体加速度驱动；
- 力对等：舱壁压力积分回刚体、把 `cdyl` 纳入更新链（目前无消费点）；
- 冰-舱壁接触：镜像/排斥力模型，避免粒子穿透；
- 验证：给定横摇（对照给定激励）与自由运动（对照解析/试验）两条路径一致。

**验收**：能量守恒（无粘情形）与运动响应可复现文献趋势。

### 阶段 3：数值质量提升（约 2–3 周）
- 启用并标定 δ-SPH 密度耗散（先单相溃坝/静水波标定 `deltf`）；
- SPT 粒子移位、自由面负压截断、自适应 CFL/时间步；
- 邻域搜索改 Verlet 表或 link-cell，降低 O(N²) 成本。

**验收**：压力场噪声下降、长时间计算稳定、同样算例耗时下降。

### 阶段 4：耦合模拟与参数化（约 4–6 周）
- 工况矩阵：波高/周期（含不规则波）、冰厚/尺寸/密集度、充液率、舱体运动幅值与频率；
- 无量纲整理：`ω/ω₁`（激励频率比）、`H/L`（波陡）、冰厚比、密集度；
- 机理分析：`波浪能 → 浮冰动能 → 碰撞冲击 → 舱体运动 → 液体晃荡` 能量传递路径与正反馈判据。

**验收**：给出影响规律曲线/经验关联式，形成论文核心章节。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 二维简化与实际三维晃荡差异 | 论文中明确适用范围；用二维典型剖面（纵/横剖）覆盖主控模态；必要时讨论三维修正 |
| 加液舱后粒子数翻倍、单机算不动 | 控制舱体尺度与网格分辨率；阶段 3 的邻域优化 + OpenMP 调优；长算例分批输出 |
| 冰-舱壁接触参数无试验依据 | 先做敏感性分析，给出参数区间；与冰-结构碰撞文献（如 Zhang 2019 IJNAOE）对标 |
| δ-SPH 与现有双时间步耦合不稳 | 先在单相水中标定，再逐级加入冰相与液舱 |
| 试验数据获取难 | 采用公开基准（Delorme 2009、Souto-Iglesias 2006、McGovern & Bai 2014）与导师课题组成熟数据 |
